# Lantern

A simple Python command-line task tracker. Lantern lets users add tasks, list tasks, and export task data as CSV.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/hazem-gamal-1/lantern.git
   ```

2. Enter the project directory:

   ```bash
   cd lantern
   ```

3. Run Lantern using Python 3:

   ```bash
   python lantern.py
   ```

## Usage

### Add a task

```bash
python lantern.py add "Complete Git project"
```

### List tasks

```bash
python lantern.py list
```

### Export tasks as CSV

```bash
python lantern.py export --csv
```

## Available Commands

- `add TITLE` — Add a new task.
- `list` — Display the tasks.
- `export --csv` — Export tasks in CSV format.
